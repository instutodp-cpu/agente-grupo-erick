# C17 — Independent Accounting Auditor

C17 adds an independent verification capability under the same Hermes/Maestro architecture. It is not another autonomous super-agent.

## Independence

The producer and verifier are logically separated. `prepared_by != audit_approved_by`.

The auditor consumes immutable evidence, canonical facts, reconciliations, journal drafts, close packages, fiscal/payroll/tax records, rule versions and approvals. Narrative generated by Hermes is not primary audit evidence.

## Assertions

The auditor tests:
- existence / occurrence;
- completeness;
- accuracy;
- cutoff / competence;
- classification;
- authorization;
- valuation;
- reconciliation;
- presentation.

## Completeness in both directions

`source → ledger` detects omitted records.

`ledger → source` detects unsupported records.

Both directions must pass.

## Independent recomputation

The intended production verifier independently recomputes critical bank, inventory, AP/AR, card, payroll, tax, ledger, DRE and fiscal tie-outs rather than trusting producer outputs.

## Evidence integrity

Evidence hashes are checked against the close package. A mutation after close invalidates the internal attestation and must trigger controlled review/reopen behavior.

## Auditor authority

The auditor may identify findings and block an attestation. It may not:
- correct journals;
- execute payments;
- submit fiscal obligations;
- mutate source records.

## Output

`InternalAuditPackage` is an internal verification package. It is explicitly not a statutory external-audit opinion.

Open critical findings produce `EXCEPTIONS`, not `PASS`.

## Gate

```text
ClosePackage
→ Independent Audit
→ PASS | EXCEPTIONS
→ Human Review
→ Accountant Handoff
```

## Not implemented

- external/statutory audit opinion;
- production recomputation adapters for every domain;
- random/surprise sampling engine;
- persistence and auditor UI.
