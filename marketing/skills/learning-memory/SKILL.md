# Marketing Learning Memory Skill

Status: evidence-ladder / scoped-memory / fail-closed.

## Purpose
Convert repeated measured marketing outcomes into reusable, scoped learning without promoting a single win or correlation into a rule.

## Inputs
- experiment results
- commercial attribution results
- creative/content performance
- contrary evidence
- existing memory and learned rules

## Outputs
A learning candidate or learned-rule update carrying evidence references, scope, confidence, contrary evidence, and validity window.

## Rules
1. Use the ladder FACT -> OBSERVATION -> HYPOTHESIS -> TESTED_INSIGHT -> LEARNED_RULE.
2. A single success never becomes a LEARNED_RULE.
3. Correlation never becomes direct attribution.
4. Preserve contrary evidence and failed experiments.
5. Scope learning to the dimensions actually supported by evidence (brand/store/audience/channel/format/product/time window).
6. Expired or contradicted learning must not silently guide new missions.
7. Memory updates must remain auditable and must not overwrite raw evidence.
