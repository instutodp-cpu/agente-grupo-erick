# Marketing Super-Skill Erick v1

Status: foundation / simulation-first / fail-closed.

## Mission
Transform a commercial objective into an evidence-backed MarketingMission:
context -> research -> hypothesis -> strategy -> production -> QA -> approval -> execution -> measurement -> attribution -> learning.

## Invariants
1. Commercial objective precedes channel and content.
2. Research before recommendation when claims depend on current external state.
3. Never invent metrics, sources, attribution, inventory, margin, or campaign state.
4. Preserve raw evidence; interpretations never overwrite evidence.
5. Correlation is never reported as direct attribution.
6. Skills request capabilities; they never receive provider credentials.
7. Financial/high-impact mutations require explicit approval.
8. No real publishing, ad spend, messaging, or destructive action is enabled by this foundation.

## Evidence ladder
FACT -> OBSERVATION -> HYPOTHESIS -> TESTED_INSIGHT -> LEARNED_RULE

Promotion requires repeated supporting evidence and must preserve contrary evidence, scope, confidence and validity window.

## Capability families
research-intelligence; strategy; creative-production; organic-distribution; paid-media; lead-conversion; measurement-attribution; learning-memory.
